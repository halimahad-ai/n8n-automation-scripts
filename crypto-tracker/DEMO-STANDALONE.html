🚀 Cryptocurrency Tracker - API Demo

Test the crypto tracker API endpoints

⚠️ Setup Required:
The API is running in a container. Enter the base URL below (if using port forwarding, it might be something like http://localhost:8000 or a forwarded URL from VS Code/Claude Desktop)

📡 API Endpoints

GET /health - Health check
GET /api/v1/cryptocurrencies - Get all cryptocurrencies
GET /api/v1/cryptocurrencies/bitcoin - Get Bitcoin details
GET /api/v1/cryptocurrencies/bitcoin/signals - Get Bitcoin signals
GET /api/v1/cryptocurrencies/bitcoin/price-history?days=7 - Get price history
GET /api/v1/dashboard - Get dashboard data

📚 Documentation

For full API documentation, visit: http://localhost:8000/docs
