Automation scripts and tools repository.

## Projects

### 🚀 Cryptocurrency Tracker & Insights Tool

A comprehensive cryptocurrency tracking and analysis application with real-time data monitoring, technical analysis, and AI-powered trading signals.

**Features:**
- Real-time cryptocurrency data from CoinGecko API
- Advanced technical analysis (RSI, MACD, SMA, EMA, Bollinger Bands, VWAP)
- Buy/Sell/Hold signal generation with confidence scores
- Interactive web dashboard
- RESTful API with FastAPI
- Support & resistance level detection
- Risk assessment and volatility analysis

**Quick Start:**
```bash
cd crypto-tracker
chmod +x scripts/quickstart.sh
./scripts/quickstart.sh
```

**Documentation:** See [crypto-tracker/README.md](crypto-tracker/README.md) for detailed documentation.
